# Working Agreement

## User communication

- Acknowledge new user messages immediately, before continuing long-running
  work.
- If a message interrupts or changes scope, explicitly say that the previous
  activity has stopped and restate the new boundary.
- Never let investigation masquerade as delivery: distinguish inspection,
  edits, and verified results.

## Design-refresh ownership

- The primary Codex agent owns product/design specifications, review, and
  acceptance criteria.
- Luna implementation agents own React and TypeScript implementation work for
  the design refresh.
- The primary agent must not edit application component code unless the user
  explicitly reassigns that work.
- The primary agent may author CSS only when the user requests it or confirms
  it is useful.
- Preserve the original product's distinctive clue-spine and linked-answer
  concepts; do not replace them with a generic crossword layout.
