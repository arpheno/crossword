# Legacy browser asset provenance

The Jinja templates intentionally reference local files so the private
continuity bridge can load without a CDN. These files are generated by
`scripts/build-legacy-assets.mjs` after `npm ci` and are ignored by git. The
lockfile, not a checked-in browser bundle, is the reproducibility source.

| Template path | npm package/version | package distribution path |
| --- | --- | --- |
| `static/lib/vue.js` | `vue@2.7.16` | `vue/dist/vue.js` |
| `static/lib/axios.min.js` | `axios@1.13.2` | `axios/dist/axios.min.js` |
| `static/lib/socket.io.min.js` | `socket.io-client@4.8.3` | `socket.io-client/dist/socket.io.min.js` |

Run `make legacy-assets` to recreate the exact three files. This is a legacy
only asset pipeline; it is not part of the future static application graph.
